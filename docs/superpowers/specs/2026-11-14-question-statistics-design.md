# 题目统计页设计

## 目标

将做题页“统计”升级为真实数据统计页，展示当前题目的总提交、通过提交、通过率、当前用户击败比例、提交结果环形图，以及每位用户一条记录的最快运行和最低内存排行榜。

## 已确定方案

- 数据只来自当前题目的 `question_submit`，不复用可能滞后的前端计数拼装排行榜。
- AC 判定为 `status = 2` 且 `judge_info.message = Accepted`。
- 排行榜按用户去重：最快榜取该用户运行时间最小的 AC，内存榜取该用户内存最小的 AC；并列时依次比较另一资源、代码长度、提交时间。
- 未登录也能查看总体统计和公开排行榜；登录用户有 AC 时返回自己的击败比例。
- 后端不返回代码正文、邮箱、提交数据库主键等敏感信息。
- ECharts 采用 `echarts` + `vue-echarts` 按需导入，只注册饼图、提示框、图例和 Canvas 渲染器。
- 不创建重复汇总表；在 `question_submit` 增加由现有 JSON/代码自动计算的生成列和索引。

## 数据库

增加 `verdict`、`runtime_ms`、`memory_kb`、`code_length` 四个 STORED 生成列，并增加两组当前题目 AC 排名索引。同步维护完整 `schema.sql`，另提供可单独执行、可重复检查的升级 SQL。

## 页面

统计页包含四张指标卡、ECharts 环形图、最快运行/最低内存切换排行榜、空状态和加载失败重试。沿用项目米白、青绿、橙色设计，窄屏自动单列。

## 非目标

- 不展示提交代码。
- 不做定时汇总任务或新增统计表。
- 不伪造无数据时的百分比和排名。

# 学生与用户管理台视觉改版设计

## 目标

将“学生管理”和“用户管理”统一为清晰、克制的教育管理后台。管理员能够快速筛选账号、理解状态、调整角色和分配师生关系；老师能够快速查看自己负责学生的学习情况。

## 设计方向

采用已确认的“现代教育管理台”方案：米白背景、白色内容面板、青绿主色、橙色提醒色。减少光晕和装饰性渐变，依靠留白、字号、边框和状态标签建立层级。

## 页面结构

- 两页共用紧凑页头、角色说明、统计卡、搜索区、加载态和空状态。
- 学生管理使用响应式学生卡片，突出头像、活跃状态、解决题数、提交数、通过率和查看记录入口。
- 用户管理桌面端使用紧凑卡片式目录，危险操作弱化到次级区域，详细登录与安全信息继续放在右侧抽屉。
- 师生分配不再要求管理员记忆雪花 ID，改为选择当前页老师与学生；保留手工 ID 作为无法搜索到目标时的补充方式。
- 手机端所有操作保持不小于 44px，统计卡两列排列，搜索和操作纵向排列。

## 状态与反馈

- 正常、受限、禁用、异常分别使用文字、图标和颜色共同表达。
- 加载时保留稳定布局；空数据说明下一步操作。
- 禁用、解除和角色切换继续使用现有确认逻辑，不改变后端权限。

## 非目标

- 不新增数据库表。
- 不改变学生、老师、管理员权限矩阵。
- 不引入新的 UI 框架或图标库。

## 已选方案与取舍

- 已选：卡片与数据表之间的平衡型教育管理台，兼顾信息密度和亲和感。
- 未选：全大卡片，视觉活泼但大量账号浏览效率低。
- 未选：纯数据表，扫描效率高但移动端和教学场景过于冷硬。
